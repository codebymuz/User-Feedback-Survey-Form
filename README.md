# User Feedback Survey Form

A simple **HTML-only survey form** to collect user feedback.  
This project demonstrates basic form creation and structure using HTML.

## Features
- Fully functional survey form with input fields
- Organized and readable HTML structure
- Easy to open and use (just open `index.html` in a browser)

## How to Use
1. Clone or download this repository.
2. Open `index.html` in any web browser.
3. Fill out the survey and submit.
