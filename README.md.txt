# User Feedback Survey Form

A simple **HTML-only survey form** to collect user feedback.  
This project demonstrates basic form creation using HTML and provides a clean, easy-to-use survey interface.

---

## Features
- Fully functional survey form
- Organized and readable HTML structure
- Simple to open and use (no setup required)
- Works in any modern web browser
